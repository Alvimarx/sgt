# HUAP

### Proyecto de Gestión de Turnos para el Hospital de Urgencia de Asistencia Pública (HUAP)

Este proyecto tiene como objetivo principal desarrollar una plataforma de Sistema de Gestión de Turnos (STG) específicamente diseñada para el Hospital de Urgencia de Asistencia Pública (HUAP).

### Instrucciones de Instalación

Para comenzar con el proyecto, sigue estos pasos:

1. **Clonar el Repositorio:**

   * Clona el proyecto utilizando HTTP si estás en Windows o SSH si estás en Linux.

2. **Requisitos Previos:**

   * Asegúrate de tener instalado Node.js y npm en tu sistema.
   * Abre el proyecto en tu IDE de preferencia.

3. **Instalación de Dependencias:**

   * Ejecuta el comando `npm install` en tu terminal para instalar todas las dependencias necesarias.

4. **Ejecución del Proyecto:**

   * Una vez instaladas las dependencias, ejecuta `npm run dev`.
   * El proyecto se levantará en dos direcciones IP: una local y otra para el acceso desde dispositivos dentro de la red.
